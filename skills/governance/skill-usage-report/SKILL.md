# Skill Usage Report

## Procedure

1. List only Skills whose instructions materially affected routing, actions,
   validation, or output.
2. Label each as primary, supporting, or reporting and state its concrete
   contribution in one short phrase.
3. When no task-specific Skill was used, state `task Skill: none` while still
   naming this reporting Skill.
4. Include one revision signal only when a Skill was missing, redundant,
   ambiguous, too costly, or insufficient.
5. End with the localized fixed receipt:
   - Skill usage
   - Primary
   - Supporting
   - Reporting: `skill-usage-report`
   - Revision signal

## Stop conditions

Do not list an available or inspected Skill that did not affect the work. Do not
invent a revision signal or omit explicit non-use.

## Completion criterion

This skill is complete when:

1. every materially used Skill is named
2. considered-but-unused Skills are excluded
3. roles and contributions are visible
4. non-use is explicit when applicable
5. a revision signal appears only when evidence supports it
