# Japanese Email Rules

## Purpose

Rules for Japanese emails to professors, university staff, companies, and collaborators.

## General style

Use:

- concise polite Japanese
- short sentences
- purpose-first structure
- natural tone
- necessary details only

Avoid:

- excessive keigo
- long background explanations
- repeated apologies
- overly complicated sentence structures
- unnecessary technical detail

## Standard structure

```text
〇〇先生

いつも大変お世話になっております。
姜です。

[目的・要件]

[必要最小限の補足]

お手数をおかけいたしますが、
何卒よろしくお願いいたします。

姜 泉
```

## Professor emails

Rules:

1. State the request or confirmation early.
2. Keep the reason short.
3. Avoid too much technical explanation.
4. Use natural academic Japanese.

## Company technical inquiry emails

Include only necessary technical facts:

1. sample geometry
2. temperature range
3. atmosphere
4. acceptable constraints
5. what the user can provide
6. what needs confirmation

## Preferred phrases

- いつも大変お世話になっております。
- 承知いたしました。
- ご確認いただき、ありがとうございました。
- お手数をおかけいたしますが、何卒よろしくお願いいたします。
