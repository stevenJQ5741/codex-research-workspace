# IFSS and Interface Rules

## Purpose

Rules for interfacial shear strength, interface evaluation, and microstructure-property interpretation.

## Core themes

- Interfacial shear strength evaluation.
- Single-fiber or microscale interface testing.
- Interface-controlled mechanical performance.
- Cellulose fiber-reinforced thermoplastics.
- Short-fiber and continuous-fiber composites.
- Flexural, impact, ILSS, and IFSS relationships.

## Core rules

1. Do not claim that interface strength alone explains all macroscopic behavior.
2. Consider fiber length, orientation, dispersion, cross-sectional geometry, voids, matrix properties, and processing history.
3. Connect micro-scale IFSS to macro-scale properties cautiously.
4. Separate failure mode observation from mechanism interpretation.
5. Avoid one-to-one causality unless directly supported.

## Preferred wording

Use:

- interfacial condition
- interface-dominated failure
- interface-related improvement
- microstructure-guided interpretation
- suggests improved load transfer

Avoid unsupported:

- interface alone caused the improvement
- IFSS completely explains the macroscopic behavior
- the interface was perfectly optimized
