# Presentation Rules

## Purpose

Rules for academic presentations, conference slides, lecture slides, and research group presentations.

## General style

Preferred:

- white academic background
- simple structured layout
- dark gray or black main text
- red only for key warnings or emphasis
- consistent terminology
- consistent figure style
- one dominant message per slide

Avoid:

- decorative dashboards
- excessive icons
- text-heavy slides
- hero-style visual slides unless requested
- unnecessary visual complexity

## Slide-title rule

A slide title should state the message, not only the topic.

Weak:

> DSC Results

Better:

> Broad Endothermic Behavior Suggests a High-Softening Range

## Workflow

1. Define audience.
2. Define deck-level narrative.
3. Decide the evidence form.
4. Select slide archetype.
5. Build slide structure.
6. Add concise text.
7. Check consistency.
8. Track unresolved issues.

## Language

- English slides: compact, defensible, conference-style.
- Japanese slides: slightly more explanatory, suitable for lectures and internal discussion.
- Chinese slides: formal, concise, direct.
