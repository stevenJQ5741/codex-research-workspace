# Project Brief Index

Project briefs hold project-specific facts, parameters, scope, and evidence
boundaries. They are working context, not automatically validated evidence.

| Brief | Scope |
| --- | --- |
| `ilss-reheating.md` | moving heat-source, DSC, and ILSS working context |
| `natural-fiber-programs.md` | tri-country natural-fiber, IoT, and related project concepts |
| `mrs-fall-2026.md` | presentation identity fields that may be reused |

Do not place credentials, submission control IDs, identity-document numbers, or
other private identifiers in project briefs. Store validated data and source
artifacts in the appropriate project workspace and link them only when needed.
